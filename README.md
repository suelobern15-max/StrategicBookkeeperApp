# Strategic Bookkeeping Feasibility Study Simulator

Interactive training simulator to evaluate growth decisions using bookkeeping-grounded data and feasibility rules.

## Launch locally

```bash
python3 -m http.server 4173
```

Open: `http://localhost:4173`

## Deploy (static hosting)

This app is plain HTML/CSS/JS and can be deployed to any static host:

- **Netlify**: drag-and-drop the repo folder into Netlify Deploys.
- **Vercel**: `vercel --prod` from the repo root.
- **GitHub Pages**: publish the repository root as Pages source.
